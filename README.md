# Aetheria Unified Memory v5.4 — Semantic Baseline Index

SillyTavern third-party memory extension for the Aetheria AIRP project.

## Install

In SillyTavern, open **Extensions → Install Extension** and paste:

```text
https://github.com/Icey0111/Memory-plugin
```

The extension requires SillyTavern's built-in `vectors` extension.

Current version: **5.4.0**
