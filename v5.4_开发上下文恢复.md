## Baseline 语义

Baseline = “删掉剧情聊天，只保留 Persona / 角色卡 / 当前世界书，仍然成立的事实”。

剧情 Memory = 相对于 Baseline 的后天增量。

知识例外：
- 世界书：X存在。
- 剧情：平成首次知道X。
- 应保存 `knowledge: 平成知道X`，不能把 X 本身重复当 world fact 存。

## Baseline 来源

稳定来源：
- Persona description
- 当前 character description/personality/scenario
- group member cards（best effort）
- embedded character_book
- Persona-bound lorebook
- character-bound lorebook
- chat-bound lorebook

volatile来源：
- 当前 activated World Info dry-run prompt

volatile World Info：进入 extractor hint + lexical gate，但不进入稳定 Baseline Vector corpus，以免关键词激活集合每轮变化造成全量向量重建。

## 写入门 eligibility

默认 gate：
- stable state
- relation
- commitment
- ownership

默认豁免：
- event
- knowledge
- belief
- intention
- world_delta
- 明显 dynamic state（hunger/location.current 等）
- 显式 change semantics（搬家/失去/获得/解除/转专业等）

## 数据权威层级

```text
Persona / Character / World Info = baseline authority
Extraction transactions           = replayable memory transactions
Canonical Memory                  = story-memory authority
Memory Vector                     = rebuildable past-recall projection
Baseline Vector                   = rebuildable baseline-dedupe projection
```

Baseline 原文不复制进 chat metadata；只保存 fingerprint、来源摘要、count、vector status 和 gate diagnostics。
